## 📝 Descripción
Aplicación de consola desarrollada en C# para la gestión de transacciones bancarias básicas. El sistema permite registrar la información de un cliente, capturar depósitos a su cuenta, calcular el nuevo saldo disponible y presentar un resumen financiero claro con formato de moneda.

El desarrollo de este proyecto fue gestionado utilizando **Git**, aplicando la convención de **Conventional Commits** para registrar la evolución progresiva del código en cada etapa requerida por el mandato.

---

## 🚀 Funcionalidades
1. **Captura de datos:** Lectura por consola del nombre del cliente, saldo actual y monto a depositar.
2. **Cálculo de saldo:** Procesamiento matemático para determinar el saldo actualizado (`Saldo Actual + Monto a Depositar`).
3. **Resumen visual:** Formato claro y estructurado con soporte de moneda del sistema (`:C`).

## 📌 Historial de Commits (Evolución del Proyecto)
El proyecto cumple con el flujo de control de versiones solicitado en la guía, registrando los siguientes hitos:

1. `feat: crear proyecto inicial` — Estructura base de la solución y repositorio.
2. `feat: agregar datos del cliente` — Captura de entradas por consola (`nombreCliente`, `saldoActual`, `montoDeposito`).
3. `feat: agregar calculo del nuevo saldo` — Lógica para sumar el saldo actual y el depósito.
4. `style: mejorar presentacion de resultados` — Diseño y formato del resumen final en pantalla.
5. `docs: actualizar README con documentacion completa del laboratorio` — Documentación general del repositorio.
